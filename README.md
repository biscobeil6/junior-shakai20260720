# 中3社会 書答式アプリ v3.0

中3総復習・高校入試対策用の社会書答式アプリです。

## 収録
- 地理：436問（23単元）
- 歴史：317問（38単元）
- 公民：340問（22単元）
- 47都道府県・県庁所在地特訓：113問（3出題タイプ）
- 合計：1,206問

## 学習の流れ
1. 分野・単元を選択
2. 手書き欄に自分で答える
3. 「答えを確認」で正答・別解・学習ポイントを表示
4. ○（できた）／△（迷った）／×（書けなかった）で自己採点
5. 周回モードまたは要復習問題を反復

## 主な機能
- Apple Pencil／指で使える大きな手書き欄
- 一つ戻す／全消去
- 10・20・50問のセッション選択
- 一周するまで同じ問題を出さない周回モード
- △・×を対象にした間違い見直し
- 10問ごとのごほうび画像
- 進捗はブラウザのlocalStorageへ保存
- 公民の時点依存問題は基準時点を表示
